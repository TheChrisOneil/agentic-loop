# Senior AI Agentic Developer, Regulated and Sovereign Systems, EverBetter LLC

EverBetter builds healthcare products on both sides of the HIPAA boundary: PRO and MED under HIPAA; HEALTH as a direct-to-member sovereign app where HIPAA does not apply. You build operational agent workflows and platform software with agentic techniques, under both regimes. You report to the Head of Agentic Engineering and ship through our in-house orchestrator.

What you will do:

- Hand-manage 10 or more concurrent agents across build, test, and operations.
- Build orchestrator components: dispatch, retries, bounded fan-out, context management, model routing, cost metering, and the kill switch.
- Enforce the regime boundary in code: least privilege and PHI redaction under HIPAA; consent checks and pod-scoped access for sovereign workloads.
- Verify functionally (requirements traced to tests, contract tests, FHIR conformance) and non-functionally (performance budgets in CI, reliability, threat models, token budgets).
- Pass every gate: design validators, SecOps scans, DevOps release checks, and regression on every model change. Code writes the evidence; the model never does.

Measured by: lead time, deployment frequency, token spend per feature, change failure rate, and escaped defects.

What you bring:

- 10 or more concurrent agents hand-managed on real work.
- Orchestration code you wrote yourself.
- 5 or more years of software engineering, including 2 or more on production LLM agents.
- Agentic code shipped under a compliance regime.
- Strong Python or TypeScript and a security mindset.

How we evaluate:

1. Convert a described process into a design that passes the validator with zero failures.
2. Build one feature with agentic tooling, with its checks, gate results, and token spend.
3. Add a retry policy or cost cap to a small orchestrator, with tests and an injected failure.
